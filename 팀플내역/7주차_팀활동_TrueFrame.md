## 0. 프로젝트 개요

**서비스명:** TrueFrame  
**한 줄 설명:** AI 생성 영상이 일상화된 2045년, 디지털 서명 기반 출처 인증과 AI 분석을 결합하여 영상의 출처·편집 이력·조작 가능성을 누구나 확인하도록 돕는 플랫폼.

**기획 목표:** 육안으로 진짜와 가짜를 구분하기 어려워진 영상 환경에서, 단정적인 진위 판정 대신 **검증 가능한 근거를 제공**하여 사용자가 정보의 신뢰도를 스스로 판단하도록 지원한다.

**과제 범위:** 미래 서비스 기획 및 시각화. 실제 애플리케이션 구현은 이번 주차 필수 요구사항이 아니다.

## 1. 아이디어 후보 비교 및 선정 기록

### 1.1 A안 — AI 기반 식당 자동 조리 시스템

2040~2050년대 식당에서 AI와 로봇이 주문·조리 과정을 자동화하는 서비스.

| 캔버스 항목 | A안 초안 |
|---|---|
| 사용자 | 외식업 자영업자, 프랜차이즈 운영자, 빠르고 저렴한 식사를 원하는 소비자 |
| 상황 | 점심·저녁 주문 집중 시간, 심야 운영, 조리 인력 부족 상황 |
| 현재의 불편 | 인건비·구인난, 숙련도에 따른 품질 차이, 주문 대기 시간 |
| 미래의 변화 | 자동 조리로 빠르고 일정한 품질의 음식 제공 및 운영 시간 확대 |
| 핵심 경험 | 합리적 가격, 빠른 제공, 균일한 맛, 취향 맞춤 조리 |
| 필요 기술 | AI 조리 알고리즘, 로봇팔, 컴퓨터 비전, IoT 센서, 재고·위생 관리 |
| 남은 위험 | 초기 도입비, 기계 고장, 위생·안전, 일자리 영향, 복잡한 조리의 한계 |

### 1.2 B안 — AI 생성 영상 탐지 및 디지털 서명 기반 진위 검증 시스템

2040~2050년대 AI 생성 영상이 고도화된 사회에서, 촬영 시점의 인증과 영상 분석을 결합해 출처·편집 이력·조작 가능성을 확인하는 서비스.

| 캔버스 항목 | B안 초기 구상 |
|---|---|
| 사용자 | SNS 이용자, 언론인, 영상 제작자, 수사기관 |
| 상황 | SNS·뉴스·온라인 커뮤니티에서 영상이 확산되거나 증거로 활용되는 상황 |
| 현재의 불편 | 실제 촬영 영상과 AI 생성 영상의 구분이 어렵고 허위 정보가 빠르게 유포됨 |
| 미래의 변화 | 촬영 출처·편집 이력 확인으로 허위 정보에 대한 대응 능력 향상 |
| 핵심 경험 | 누구나 영상의 출처와 조작 의심 여부를 쉽게 확인 |
| 필요 기술 | AI 영상 탐지, 디지털 서명, 암호화, 카메라 보안 모듈, 콘텐츠 출처 인증 |
| 남은 위험 | 탐지 오류, 인증키 탈취, 검증되지 않은 실제 영상에 대한 불신, 개인정보 문제 |

### 1.3 선정 결과: **B안 선정 (A안 대비)**

PPT 15쪽에서 제시한 **사용자 가치, 아이디어의 새로움, 문제 정의의 근거, 향후 확장성**을 기준으로 비교했다. 아래는 기획 초안 단계의 **정성적 검토**이며 팀 투표나 공식 채점 결과가 아니다.

| 평가 기준 | A안: 식당 자동 조리 | B안: 영상 검증 |
|---|---|---|
| 사용자 가치 | 인력난·외식 편의 개선 | 허위 정보 확산과 디지털 신뢰 문제에 대응 |
| 아이디어의 새로움 | 기존 로봇 조리 시스템의 발전형 | 출처 인증과 AI 탐지를 일상 플랫폼에 통합 |
| 문제 정의의 근거 | 인건비·구인난·품질 편차 | 딥페이크·AI 생성 영상 확산, 인증 필요성 |
| 향후 확장성 | 외식업·급식·무인 매장 | SNS·언론·카메라·공공기관·디지털 증거 |

**선정 사유:** B안은 AI 고도화에 따른 미래 사회의 문제를 선명하게 제시할 수 있고, 정보보안·소프트웨어 분야와 밀접하며, 현재 존재하는 디지털 서명·콘텐츠 출처 인증 기술을 바탕으로 미래의 발전 방향을 설명하기에 적합하다. A안은 사용 장면을 직관적으로 표현하기 쉽지만, 이번 기획에서는 B안의 사회적 파급력과 기술·서비스 확장성을 더 높게 평가했다.

> **결정 상태:** B안을 최종 기획 대상으로 채택. 팀원별 평가 점수·실제 회의 기록이 필요하다면 추후 별도 추가.

## 2. 최종 미래 서비스 캔버스 (7개 항목)

| 항목 | 최종 내용 |
|---|---|
| **01 사용자 (User)** | SNS에서 영상·뉴스를 소비하는 일반 시민, 언론인, 콘텐츠 제작자, 수사기관. 주 페르소나는 일반 시민. |
| **02 상황 (Situation)** | 2045년, SNS에 사건·사고·공인의 발언 영상이 퍼지지만 실제 촬영 및 편집 여부를 확인하기 어려운 상황. |
| **03 현재의 불편 (Pain)** | AI 생성 영상이 사실적으로 발전하고 탐지만으로 진위를 확정하기 어려워, 허위 정보를 믿거나 공유할 위험이 있음. |
| **04 미래의 변화 (Change)** | 디지털 서명과 편집 이력, AI 분석을 결합한 검증 근거를 쉽게 확인하고 정보를 더 신중하게 판단하게 됨. |
| **05 핵심 경험 (Value)** | 영상을 접한 즉시 출처·편집 이력·조작 의심 징후를 한눈에 확인하는 경험. |
| **06 필요 기술 (Tech)** | C2PA 기반 콘텐츠 출처 인증, 디지털 서명·공개키 암호, 카메라 하드웨어 보안 모듈, AI 영상 분석, 편집 이력 추적. |
| **07 남은 위험 (Risk)** | AI 오탐·미탐, 인증키 탈취, 인증 정보 누락, 개인정보 침해, 실제 영상을 허위로 오해하는 문제, 장면의 맥락 조작. |

### 문제 정의 문장

> 2045년, SNS에서 정보를 접하는 일반 시민은 실제 촬영 영상과 AI 생성 영상을 육안으로 구별하기 어려워 허위 정보를 신뢰하거나 확산할 위험에 노출된다. 따라서 영상의 출처와 생성·편집 이력을 간편하게 검증할 수 있는 서비스가 필요하다.

### 핵심 사용자 페르소나

- **가상 인물:** 김민수, 29세 직장인
- **생활 패턴:** 출퇴근 시간에 SNS로 뉴스와 영상을 확인하고 공유함
- **핵심 상황:** 출근길, 논란이 되는 공인의 발언 영상을 발견
- **불편:** 실제 촬영인지 AI 합성인지, 편집으로 의미가 바뀌었는지 확신하기 어려움
- **목표:** 긴 검색이나 전문 포렌식 지식 없이 근거를 확인하고 공유 여부를 결정

## 3. 서비스 콘셉트 및 사용자 경험

### 3.1 핵심 기능 (3개)

1. **촬영 출처의 디지털 인증:** 스마트폰·카메라 등 촬영 장치가 안전하게 생성한 디지털 서명으로 인증된 장치에서 생성된 기록인지, 이후 변경이 있었는지 확인한다.
2. **AI 영상 조작 탐지:** 인증 정보가 부족하거나 의심스러운 영상의 시각·시간적 특징을 분석해 AI 생성·조작 징후를 참고 정보로 제시한다. 탐지 결과를 확정 판정처럼 표시하지 않는다.
3. **출처·편집 이력의 직관적 표시:** 검증 가능한 메타데이터와 편집 단계, 확인 불가능한 구간을 이해하기 쉬운 인터페이스로 구분해 보여 준다.

### 3.2 사용 전후 변화

| 도입 전 | 도입 후 |
|---|---|
| 영상의 진위를 육안이나 검색에 의존 | 서명·출처·편집 기록을 확인할 수 있음 |
| AI 생성 또는 조작 여부 판단이 어려움 | AI 분석 결과를 **보조 근거**로 활용 |
| 근거가 부족한 상태로 공유·확산 가능 | 확인 가능한 정보에 기반해 공유 여부 결정 |

### 3.3 핵심 작동 장면 (Magic Moment)

2045년 출근길 지하철. 이용자는 SNS에서 논란이 되는 영상 하나를 발견한다. 영상 옆 **TrueFrame 검증 정보**를 열자 촬영 출처 인증 상태, 확인 가능한 편집 이력, AI가 분석한 의심 구간이 표시된다. 이용자는 결과의 한계까지 함께 확인하고 영상을 공유할지 결정한다.

## 4. 벤치마킹과 기술적 근거

### 사례 1. C2PA / Content Credentials

- **종류:** 콘텐츠 출처·이력 관련 공개 기술 표준
- **핵심 사실:** 암호학적 서명과 메타데이터를 통해 콘텐츠의 출처 및 변경 기록을 검증할 수 있는 기반을 제공한다.
- **본 기획과의 연관성:** TrueFrame 기능 1(출처 인증), 기능 3(이력 확인)의 기반.
- **추가 확인 사항:** 플랫폼 간 메타데이터 보존, 인증 체계 상호운용성, 인증 없는 콘텐츠 처리.
- **자료:** [C2PA 기술 명세](https://spec.c2pa.org/specifications/specifications/2.2/specs/C2PA_Specification.html)

### 사례 2. Sony Camera Authenticity Solution

- **종류:** 촬영 장치 및 콘텐츠 진위 검증 솔루션
- **핵심 사실:** 카메라에서 제공되는 서명과 관련 정보를 바탕으로 콘텐츠 출처를 검증하려는 상용화 접근 사례다. 지원 기능은 기종·파일 형식·환경에 따라 확인이 필요하다.
- **본 기획과의 연관성:** 촬영 단계의 하드웨어 기반 인증을 스마트폰·CCTV 등으로 확장하는 미래 가설의 출발점.
- **추가 확인 사항:** 영상 지원 범위, 기기 보급 비용, 키 보안, 제조사 간 연동.
- **자료:** [Sony Camera Authenticity Solution](https://authenticity.sony.net/camera/)

**조사 기준일:** 2026-10-16 (기획 참고 기록). 제출 전 링크와 최신 지원 범위를 팀에서 다시 확인한다. 위 자료는 기술의 **현재 존재 근거**이며, 2045년 대중화는 **팀의 미래 가설**이다.

### 2026년 → 2045년 발전 시나리오

- **현재:** 콘텐츠 출처 인증 표준, 촬영 장치의 서명 기술, AI 영상 분석 기술이 존재하거나 발전 중이다.
- **2045년 가설:** 카메라·스마트폰과 영상 플랫폼이 표준 기반 인증을 폭넓게 지원하고 AI 분석을 보조 수단으로 통합한다.
- **차별점:** 새 탐지 모델 하나보다, 출처 인증·탐지·이력 정보를 일반 사용자가 이해할 수 있는 **통합 UX**를 설계한다.

### 반드시 지켜야 할 검증 원칙

1. **출처 인증:** 누가 또는 어떤 기기가 콘텐츠에 서명했으며, 검증 가능한 이력은 무엇인가?
2. **AI 분석:** 생성·조작의 징후가 탐지되었는가? (확률·오류 가능성을 수반)
3. **사실 확인:** 영상 속 사건·발언과 그 맥락이 실제 사실인가? (별도의 취재·검증 필요)

> **디지털 서명이 유효해도 영상 내용이 사실이라는 뜻은 아니다.** 허위 연출을 진짜 카메라로 촬영하거나, 실제 영상을 잘못된 설명과 함께 유포할 수 있다. 또한 인증 정보가 없다는 이유만으로 가짜라고 단정해서는 안 된다.

## 6. 90초 피치 초안

안녕하세요. 저희 팀이 제안하는 2045년 미래 서비스는 **AI 기반 영상 진위 검증 플랫폼, TrueFrame**입니다.

2045년에는 AI가 생성한 영상이 실제 촬영 영상과 구별하기 어려울 정도로 발전할 것입니다. SNS에서 접한 충격적인 영상이 진짜인지, 누군가 조작한 것인지 일반 사용자가 판단하기 어려워지는 것이죠.

저희는 이러한 문제를 해결하기 위해 TrueFrame을 제안합니다.

TrueFrame의 핵심 기능은 세 가지입니다.

첫째, 카메라에서 촬영할 때 생성한 디지털 서명을 이용해 영상의 출처를 인증합니다.

둘째, AI가 영상의 특징을 분석하여 생성 또는 조작 가능성을 확인합니다.

셋째, 영상의 촬영 출처와 편집 이력을 사용자에게 직관적으로 제공합니다.

예를 들어 2045년의 한 직장인이 출근길에 SNS에서 논란이 되는 영상을 발견했다고 가정해 보겠습니다. 사용자는 TrueFrame을 통해 해당 영상의 출처와 편집 이력을 즉시 확인하고, AI 분석 결과까지 참고하여 정보를 판단할 수 있습니다.

물론 이 기술만으로 영상 속 모든 내용이 사실인지 보장할 수는 없습니다. 하지만 저희는 영상의 진위를 막연히 추측하던 사회에서, **검증 가능한 근거를 바탕으로 판단하는 사회**로 변화할 수 있다고 생각합니다.

이상으로 TrueFrame을 소개해 드렸습니다. 감사합니다.

> 발표 전 90초에 맞춰 실제 낭독 속도를 확인하고 길이를 조정한다.
